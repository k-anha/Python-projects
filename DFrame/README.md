# DAM - Data Analysis Module

This is a simple implementation of python pandas library based on numpy engine for faster calculations and data handling.

### Examples :

```Python
imoprt dam

# Your data frame goes here
df = dam.DFrame(
        [[1,2,3],[6,4,5],[7,8,9]],
        columns=["A", "B", "C"]
    )

print(df)
```
